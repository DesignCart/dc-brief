# DC BRIEF – Joomla Brief Generator 🧩✨

**DC BRIEF** is a Joomla module designed to collect detailed project briefs directly from your website.  
Instead of a simple contact form, users fill in a structured, configurable brief inside a modern animated modal — without leaving the page.

---

## ✨ Key Features

- 📝 **Dynamic brief builder** (groups + fields)
- 🎨 **Custom modal UI** (not Bootstrap-based)
- 🌈 **Animated gradient backdrop** for immersive UX
- ⚡ **AJAX submission** (no page reload)
- ✅ **Frontend validation** for required fields
- 📬 **Email delivery** with full, structured brief
- 📱 **Responsive design** (desktop & mobile)
- 🧩 **Multiple instances support** per site

---

## 🛠 How It Works

1. User clicks a button on the page
2. A custom animated modal opens
3. The brief form is generated dynamically from module settings
4. Data is validated on the frontend
5. The brief is sent via AJAX
6. A complete, structured email is delivered to the administrator

---

## 📦 Installation

1. Download the module package
2. Install it via **Extensions → Install** in Joomla
3. Publish the module
4. Assign it to a menu item or page
